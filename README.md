# GlobalTNA Job Board - Full Stack Intern Assignment

A mini service request board built with Next.js, Express, and MongoDB (Compass). Homeowners can post jobs, tradespeople can manage them.

## 🛠️ Tech Stack
- **Frontend:** Next.js 14 (App Router) + Tailwind CSS
- **Backend:** Node.js + Express
- **Database:** MongoDB + Mongoose (local with Compass)

## 🚀 Setup Instructions

### Prerequisites
- Node.js (v18 or higher)
- MongoDB Compass (with local MongoDB Server running)
